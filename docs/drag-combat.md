# 드래그 전투

토너먼트와 사냥터는 동일한 드래그 전투 규칙을 사용한다. 캔버스에서 공을 반대 방향으로 당겼다가 놓으면 한 번의 충격으로 발사한다.

## 조준과 발사

- 조준 중에는 시간 왜곡으로 자신 이외의 흐름이 35% 속도로 진행한다.
- 조준은 1.2초 뒤 현재 벡터로 자동 발사된다. 발사 뒤에는 2초 재사용 대기시간과 충돌 반동 잠금이 적용된다.
- 릴리즈 충격량은 캐릭터 기본 속도의 최소 1.25배에서 최대 3.20배까지 당김 강도에 따라 증가한다. 조준 궤적은 현재 속도와 이 충격량을 합친 실제 발사 속도를 사용한다.
- 각 적은 발사 순간의 플레이어 위치를 향한 180도 방패를 고정한다. 방패 정면으로 바로 부딪히면 플레이어만 크게 손해 본다.
- 발사는 최초 캐릭터 충돌, 느려짐, 또는 최대 비행 시간으로 끝난다.

## 반사 보상과 적 공격

- 현재 물리 경로는 최대 3회 반사를 미리 보여 준다. 1회 반사는 정상 후면 피해, 2회는 강화 피해, 3회 이상은 최대 피해와 경직을 준다. 4회 이상은 연출만 누적한다.
- 적은 한 명씩 예고 후 고정 벡터로 돌진한다. 적 돌진은 자연 충돌보다 피해가 1.35배지만, 적에게는 방패·반사 보상이 없다.
- 예고 중 올바른 드래그로 돌진을 피하면 다음 적의 발사가 기존 드래그 대기시간까지 늦어진다. 공격적으로 드래그해 맞으면 그 보호를 잃는다.

## 자동 전투와 밸런스

자동 진행은 드래그 전용 반사 보너스를 사용하지 않는다. 낮은 사냥터는 자동 진행을 허용하되, 높은 층과 토너먼트는 적의 낮은 체력과 높은 돌진 피해를 통해 회피와 반사 각도를 요구한다. 드래그 매치의 1대1 적 최대 체력은 시작 시 한 번만 50%로 조정한다. 다수전은 `아군 수 / 적군 수` 비율의 3제곱을 추가 적용해 적 수가 늘어날 때 적 진영의 총 체력 부담이 선형으로 폭증하지 않게 하며, 각 전투원의 현재 체력 비율은 보존한다.

## 소유권과 검증

입력·릴리즈 속도·방패·반사·순차 돌진과 적 체력 설정은 `src/combat-drag/`가 소유하고, 궤적은 `trajectoryScene`, 화면 표현은 `DragCombatRenderer`가 맡는다. `BattleSimulation.setPlayerBall()`은 플레이어 지정과 팀 인원수 기반 적 체력 조정을 한 곳에서 처리한다. 회귀 테스트는 릴리즈 속도와 궤적의 동일 설정 사용, 체력 배율의 정확히 한 번 적용, 체력 비율 보존, 교체·부활·새 매치, 입력 잠금과 적 돌진을 확인한다.

개발자 모드의 `드래그 전투 튜닝`은 릴리즈 속도를 기본값의 0.60~1.80배로 조절한다. 이 값은 저장 프로필에 기록하지 않는 현재 세션 전용이며, 다음 토너먼트와 사냥터 전투를 만들 때 발사 충격량과 조준 궤적에 함께 주입된다. 디버그 모드를 종료하면 1.00배로 돌아간다.
